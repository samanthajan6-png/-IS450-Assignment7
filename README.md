## Description

The Python program simulates rolling a six-sided die 20 times and records the
result of each roll.

## Input

The program does not require user input.

## Output

The program records the results of 20 die rolls. Each result is a number from
1 to 6. It also calculates and displays the average of those 20 results.

## How to Run

From a terminal, navigate to the directory containing the Python program and
run:

```bash
python3 program.py
```
